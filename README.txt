AGIWC website – design preview (Version 3)
==========================================

How to open it:
1. Unzip this folder.
2. Double-click index.html (or drag it into Chrome).
3. Click around: the menu, buttons and footer links take you between all 6 pages.
   The moon/sun button switches dark mode, and it remembers your choice.

This is the TARGET, not your code.
It was generated from the design canvas, so it's written with inline styles everywhere,
not how we'll write it together. Don't copy from it: look at it to see where you're
heading, then build your own version week by week from the schedule.

Text in [square brackets] = real content still needed from the church.
(It needs internet for the font, Plus Jakarta Sans. Offline it falls back to a system font.)
